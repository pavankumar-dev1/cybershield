# Security Policy

## Scope

CyberShield is an educational toolkit. Its automated checks are heuristic indicators, not a complete vulnerability assessment, breach lookup, antivirus product, or threat-intelligence feed.

## Supported use

Use the application only with information, devices, URLs, and networks you own or are explicitly authorized to assess. Do not submit real passwords, private messages, or other secrets to a hosted instance.

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal data, or an unpatched vulnerability in a public issue. Contact the repository maintainer privately through the contact method listed on the GitHub profile and include:

- A concise description of the affected component.
- Reproduction steps using a harmless test case.
- The potential impact and affected version or commit.
- Any suggested mitigation.

Allow reasonable time for investigation and remediation before public disclosure.

## Important limitations

- A SAFE result does not prove that a password, URL, application, or network is secure.
- Keyword matching can produce false positives and false negatives.
- URL indicators are heuristic and do not query a live reputation or blocklist service.
- Never use the tool's output as the sole basis for a security decision.
